# Редизайн ГЕРА₂ — заметки

Стек не менялся: Astro 6.1.9 (static), scoped CSS, vanilla TS, модалки
`free-astro-components`. Шрифты хранятся локально: Anton и Anton Cyrillic для крупных заголовков,
Roboto для основного текста, Oswald для узких подписей и кнопок, IBM Plex Mono
для технических подписей. Исходник и OFL-лицензия Anton Cyrillic — в `src/assets/fonts/`.

```sh
pnpm install
pnpm dev      # localhost:4321
pnpm build    # dist/
```

## Что сохранено

- SEO-метаданные в `Layout.astro` — без изменений.
- Гео-логика ipinfo: BYN для Беларуси, RUB для остальных и при ошибке запроса — как раньше.
- Cookie-модалка и `localStorage`-флаг `welcome_modal_shown`.
- Заявка: модалка контактов, сообщение «Здравствуйте! Хотел бы заказать …» и
  подстановка текста в WhatsApp / Viber / Telegram. Теперь в текст попадают
  модель, номер и текст комплектации, цена и компрессор.
- Якорь конфигуратора `#tool_options`.
- Ролики `wwzq9kUryF8`, `AczPuWS2BeQ`: плеер (youtube-nocookie) загружается только по клику.

## Ролики

Настройка — `MEDIA_SECTION_DATA.VIDEOS` в `mediaSectionData.ts`. Поле `id` принимает
ID или полную ссылку (watch / youtu.be / shorts / embed). При пустом массиве
показывается превью без плеера.

## Требует внимания

- **Опечатки в исходных текстах** выводятся как есть, по требованию «1 к 1»:
  «Преднозначен», «компрессоров.Экономичен», «производстве(малярные мастерские,СТО)»,
  «абразива(1 разгонная…», «эфективность», «образива». Исправлять нужно
  в `mediaSectionData.ts` и `benefitsSectionData.ts`.
- **Цены**: значения BYN из ТЗ совпадают с кодом. Расхождение одно: ТЗ говорит
  «цена в BYN», а сайт показывает RUB (3000–5500) всем, кто не из Беларуси, —
  логика оставлена. Актуальность цен на gera2.by проверить не удалось: на
  странице они не видны без JS.
- **Иллюстрации**: изображения восстановлены встроенным ImageGen по двум
  предоставленным макетам, это не фотографии испытаний аппарата. Файлы и промпты —
  `src/assets/metal/`. Для первого экрана используются отдельные desktop/mobile
  изображения, для ползунка — два совмещённых состояния одной детали. Astro
  выпускает WebP. SVG-фильтр ржавчины больше не используется в этих секциях.
- **Превью видео** — сохранённые `thumbFirstVideo/SecondVideo.avif` (480×360,
  вертикальный ролик). Для чёткого 16:9 нужен кадр в большем разрешении.
- Подписи-слоганы из макета («Точность в каждой детали», «Три модели. Больше
  возможностей») оставлены как в референсе — при желании убрать в `pageContent.ts`.
- Нет адреса и e-mail продавца — на исходном сайте их тоже нет.
- Строка 02 «Классик» в списке моделей подсвечена по умолчанию (как в макете);
  при наведении подсвечивается строка под курсором.

## Уточнения по референсам

- Заголовки, межбуквенные интервалы, размеры SVG-стрелок и мобильные пропорции
  настроены по присланным изображениям. Цифра 2 в бренде всегда акцентного цвета.
- Секция моделей идёт сразу за сравнением; видео — после конфигуратора.
- Ползунок сравнения использует один нативный range на всю площадь изображения:
  мышь, touch, стрелки, Home и End.
- Cookie-окно: непрозрачный светлый фон, тёмный текст, чёрная кнопка с белым текстом.
- Проверены ширины 320, 390, 520, 768, 946 и 1440 px, выбор комплектации и сборка.
